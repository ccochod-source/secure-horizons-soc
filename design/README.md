# Direction visuelle V0

`trace-direction-v0.png` est une planche de concept générée pour explorer la direction artistique. Ce n'est pas une capture de l'application, ni une représentation des mesures réelles de défense. Les textes et chiffres illustratifs ne doivent pas servir de preuves dans le pitch.

L'interface implémentée est dans `frontend/` et se consulte sur http://localhost:3100 après démarrage.

Nom de travail : TRACE. Palette graphite, blanc doux, menthe, ambre et rouge ; hiérarchie sobre ; traces et décision humaine mises en avant.
